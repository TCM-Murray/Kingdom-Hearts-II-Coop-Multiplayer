### Key design insight (needs user decision)
Both co-op projects independently moved to a "local-primary" model: each human is the native player (slot 0) on their own PC, and the other human appears as a puppet in a party slot. Reason: making a friend/AI actor accept full controller input (attack, jump, guard) is the hardest RE problem; Volpestyle has movement only after months. The user's brief (P2 = friend-slot Roxas driven by a 2nd controller) is the hard path. See MODDING_PLAN.md §3.

1. **Trigger boxes are checked against one position, the local player's.** Each game spawns a group only when *its own* Sora walks into the group's box.
2. **RandomSpawn / CasualSpawn** script commands (opcodes 2, 3) pick with the game's RNG (exe+0x783CA0, LCG x0x10DCD): two PCs can pick different groups.
3. **Enemy history** (recently defeated serials don't respawn for N room changes) is per PC.

### Data (verified by parsing `ard/us/hb09.ard` with a scratch script; matches the live spawns exactly)
- Room scripts `map`/`btl`/`evt` (BAR type 0xD); program = {u16 id, u16 len, ops}; op 0 `Spawn` lists spawn files by 4-char name (`b_00`...). OpenKH doc: docs/kh2/file/type/areadata.md. Research parser (outside the repo): `D:	ools\kh2-ghidra\scripts\spawnparse.py <unpacked .spawn files>`; unpack a room with `OpenKh.Command.Bar.exe unpack <ard> -o <dir>`.
- Spawn file (BAR type 0xC): {int 2, int groupCount}, then per group a 0x2C-byte descriptor {u8 **type** (2 = enemies; 1 entrance spawn, 3 event, 6..9 others incl. map change), u8 flag, u16 **id** (unique, e.g. 243..248), u16 entityCount, u16 activatorCount, u16 walkCount, u16 returnCount, int signalCount, ..., u8 area, u8 entrance, ...}, then entities (0x40 each: int objId, f32 x,y,z, f32 rot x,y,z, u8 spawnType @0x1C (2 = waits for its trigger, 0/1/3 spawn on activation), u8 spawnArg @0x1D (1 near player, 2 random in radius), u16 **serial** @0x1E, int arg1, arg2, ..., u16 delay @0x2A, ..., u8 wave @0x30), then activators (0x40 each: u16 shape, u16 option, f32 pos x,y,z, f32 scale x,y,z, rot, flags, type...), walk paths, return params, signals.
- hb09 b_00 group 2 (id 245) = the 4 Shadows we saw: M_EX020 at (907,-160,-352) serial 80 delay 25, (619,-100,-89) s79, (875,-100,50) s76, (501,-100,-484) s77; box centre (522,-128,-324) scale (590,139,604). Groups 0/1 = the M_EX010 at (-419,-151,-1832), (-669,-301,-1682), (-744,-1,-303).
