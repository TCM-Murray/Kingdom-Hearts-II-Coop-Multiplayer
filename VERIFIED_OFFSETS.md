The generic actor update `exe+0x3BFD30` calls handler slot `+0x40` (Shadow: thunk `0x419B90` → `exe+0x3DAC30`) only when actor `+0x120` bit 28 is set. If that returns true, slot `+0x48` (`0x419BA0` → `0x411800`) disposes of the actor. `0x3DAC30` steps the AI script (`0x3B4420` → `0x3E1C80`) and returns true once the script-thread count `+0x5B8` is 0 (gated by `+0x80`/`+0x98` and the `+0xBB4` child).
